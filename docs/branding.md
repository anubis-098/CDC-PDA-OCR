# UI branding

Updated 2026-10-27.

- UI font: [Sarabun on Google Fonts](https://fonts.google.com/specimen/Sarabun), weights 400/500/600/700, loaded using Google Fonts CSS with `display=swap` and preconnect. Tahoma/sans-serif are fallbacks if the network cannot reach Google Fonts.
- Palette reference: [CJ Logistics official Brand Story](https://www.cjlogistics.com/en/about/brand/story): CJ Blue `#0080c6`, CJ Red `#e42f44`, CJ Yellow `#ec8922`, CJ Silver `#cdcdce`.
- Primary buttons and links use a darker blue `#006ba6` for readable white button text; header accents and capture-card borders use the CI palette. Green result badges retain their success meaning.
- The Korean wordmark was replaced with an English "LOGISTICS" label beside the original CJ blossom/CJ symbol in `frontend/public/cj-logistics.svg`, so the header reads CJ LOGISTICS on desktop and portrait screens.
- The document/check PWA icon is the application's own icon in the updated palette, not a replacement or recreation of the company logo.
- Sarabun is the requested application font; this implementation does not claim to replace the corporate typography guidelines or certify the UI as formally approved by CJ Logistics.
