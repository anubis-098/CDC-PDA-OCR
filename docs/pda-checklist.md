# รายการตรวจรับบน PDA Zebra

สถานะปัจจุบัน: ยังไม่ได้ทดสอบจริง

| รายการ | ค่า / ผล |
| --- | --- |
| รุ่น Zebra | ยังไม่ระบุ |
| Android / build | ยังไม่ระบุ |
| Browser / Enterprise Browser version | ยังไม่ระบุ |
| Kiosk / MDM permission policy | ยังไม่ระบุ |
| URL HTTPS / certificate chain | รอตรวจ |
| วันที่และผู้ทดสอบ | รอตรวจ |

- [ ] เปิด URL ผ่านเครือข่ายหน้างานและ certificate เชื่อถือได้
- [ ] เปิดกล้องหลังจากแตะปุ่มเท่านั้น; อนุญาตและปฏิเสธสิทธิ์แล้วมีข้อความที่เหมาะสม
- [ ] กล้องหลัง / preview / จับภาพ / ถ่ายใหม่ / ใช้ภาพนี้ ทำงาน
- [ ] ไฟแสดงการใช้กล้องดับหลังถ่าย ยกเลิก เปลี่ยนแอป หรือออกหน้า
- [ ] อ่านตัวเลขบน preview ได้ในจอแนวตั้ง และปุ่มกดสะดวกที่ความกว้างจริง
- [ ] การเลือก JPG/PNG และ PDF จาก Android file picker ทำงาน
- [ ] PDF หลายหน้าและเกิน 5 หน้าแสดงผลหรือปฏิเสธถูกต้อง
- [ ] ภาพเกิน 10 MB, ภาพใหญ่เกิน 25 MP และไฟล์ผิดชนิดถูกปฏิเสธ
- [ ] ภาพหมุนจาก EXIF, เอียง, มีเงา, แสงน้อย ไม่ถูกตัดสินผ่านเมื่อค่าไม่ชัด
- [ ] ตัวอย่าง PO 1132536, CS 1 ↔ 1.00 ตรงหลังอ่าน/ตรวจทาน
- [ ] CS 1 ↔ MU 5 แสดงหน่วยไม่ตรงกัน
- [ ] PO ต่าง, QTY ต่าง, ไม่พบค่า, confidence ต่ำ แสดงผลที่เหมาะสม
- [ ] หลายรายการสลับลำดับจับคู่ด้วยรหัส; รหัสซ้ำ/ไม่ครบต้องตรวจทาน
- [ ] แก้ค่าแล้วระบบบันทึกและคำนวณใหม่อัตโนมัติ ประวัติยังมีค่าดิบ
- [ ] เปิดสองหน้าจอแก้รายการเดียวกัน แล้ว revision เก่าถูกปฏิเสธ
- [ ] ปิดเครือข่ายระหว่างส่งแล้วลองใหม่ได้โดยไม่ต้องถ่ายใหม่
- [ ] เปิดประวัติหลังรีสตาร์ต Compose แล้วยังพบข้อมูล
- [ ] ติดตั้ง PWA และเปิด standalone ได้ตาม browser ที่องค์กรเลือก
- [ ] ตรวจว่า backend โหลดโมเดลจริงสำเร็จ และทดสอบเวลาที่รับได้บน CPU ของเซิร์ฟเวอร์

แนบผลจริงโดยไม่ใส่เอกสารลูกค้า/ข้อมูลส่วนบุคคลลง Git หากแบบฟอร์มตารางยังอ่านไม่ครบ ให้ปรับ extraction ด้วยข้อมูลจำลองที่สะท้อน layout และทดสอบซ้ำก่อนยืนยันว่า OCR ใช้หน้างานได้
